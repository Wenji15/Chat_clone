# 微信自动回复机器人（独立运行版）

脱离 AI 助手后，本机可自行运行。原理是**屏幕级 RPA**：

```
抓微信窗口(PrintWindow) → 裁聊天区 → OCR → 判断谁说的 → 本地分身生成回复 → 模拟输入发送
```

不 hook 微信、不注入进程、不调用微信接口，只"看屏幕 + 敲键盘点鼠标"。

---

## 前置条件

1. **Ollama 在运行**（任务栏有 🦙；`ollama list` 能看到 `qwen3.5:9b`、`bge-m3`）
2. **微信已登录**（微信 4.x）
3. Python 依赖已安装（`rapidocr-onnxruntime`、`pyautogui`、`pyperclip`、`pillow`）
4. ⚠️ **微信必须停在目标聊天窗口**——机器人只读"当前打开的那个聊天"，**不会自动切换会话**

---

## 配置

编辑 [bot_config.json](../bot_config.json)：

| 字段 | 说明 |
|------|------|
| `target` | 只回复标题含此名的会话（强烈建议保留，防止误回别人） |
| `interval` | 轮询间隔（秒） |
| `cooldown` | 两次回复最短间隔（秒） |
| `live` | `true` 真发送；`false` 只打印不发送（建议先跑 false 观察） |
| `log` | 日志文件路径 |

---

## 启动 / 停止

| 操作 | 方式 |
|------|------|
| 启动 | 双击 `run_bot.bat`（会先检查 Ollama） |
| 停止 | 双击 `stop_bot.bat`，或控制台 `Ctrl+C` |
| 急停 | 鼠标猛移到**屏幕左上角**（pyautogui FAILSAFE） |
| 单次测试 | 双击 `run_dry.bat`（只识别+拟回复，不发送） |

## 开机自启（可选）

**方法一：启动文件夹（最简单）**
1. `Win + R` 输入 `shell:startup` 回车
2. 把 `run_bot.bat` 的快捷方式放进去

**方法二：任务计划程序**
1. 打开"任务计划程序" → 创建基本任务
2. 触发器：**登录时**
3. 操作：启动程序 → 选 `E:\agent_engineer\AI_clone\run_bot.bat`

> 开机自启后，若微信还没登录，机器人会每 5 秒重试，登录后自动开始。

## 限制与风险（务必了解）

- **必须保持目标聊天打开**：最小化或切走会导致抓不到；关闭聊天则待命
- **表情 / 图片 / 语音没有文字** → 不回复（安全跳过）
- **OCR 偶有错字**，可能误解消息，建议别完全无人值守
- **回车发送**：若你微信设置的是 `Ctrl+Enter` 发送，它会只填入不发送（安全失败）
- **账号风险**：屏幕模拟比注入温和，但自动化仍可能触发微信风控，**别高频、别群发**
- 窗口尺寸变化后，坐标可能偏；必要时微调 `scripts/wechat_screener.py` 顶部的 `CHAT_X0_PX` / `INPUT_Y_MARGIN`

---

## 故障排查

| 日志现象 | 原因 / 处理 |
|---------|------------|
| `[wait] 未找到微信窗口` | 微信没开 / 没登录 |
| `当前会话 '' ≠ 目标` | 没打开目标聊天，或标题 OCR 失败 |
| `[error] 生成回复失败` | Ollama 没运行 |
| 发送后内容为空 | 输入框点击坐标偏了，检查窗口尺寸 |
| 一直 `[cool] 冷却中` | 正常，防连环回复 |
